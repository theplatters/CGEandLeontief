# Prompt: manuscript cleaner (Beyond Hulten revision)

Use this prompt for a subagent or an external model doing a **consistency pass**
over `revision/sections/*.tex`. It is a *cleaning* pass, not a rewrite: no
argument changes, no new claims, no new numbers.

---

## Task

You are cleaning the LaTeX sources of a journal revision so that terminology,
notation and number style are uniform across sections and appendices. Work file
by file, in this order: `(2)transformation-to-io.tex`, `(3)two-primitive-questions.tex`,
`(4)kernel-closures-financings.tex`, `(5)application.tex`,
`(6)beyond-demand-only.tex`, `(A)equivalences.tex`, `(B)model-closures-proofs.tex`,
`(C)data-pipeline.tex`, `(D)matrix-variants.tex`, `(E)pricing-door.tex`.

## Rules

1. **Terminology the paper does not use — delete on sight.**
   - `Type~I` / `Type~II` (say instead what the figures are: technological
     coefficients, or that they contain no induced household demand).
   - `direct leg` / `embodied leg` / `leg` as a metaphor for the stages of an
     input–output calculation.
   - Any `canary` in prose that reaches the reader (a canary is a developer
     term; keep the word only inside code comments and `.tex` source headers).
2. **Percentages.** Write the symbol, not the word: `$17.8\%$`, never
   `17.8 percent` / `per cent`. This includes `$56\%$ of the program's size`.
   Do not convert per-euro decimals into percentages or the reverse: a share of
   a base keeps the `\%`, a ratio to another unit keeps the decimal.
3. **Spelling.** American: labor, modeling, behavior, center, normalize,
   organize, analyze, defense. Keep `program` for the policy program and
   `programme` out entirely.
4. **Numbers.** Thousands separators in math mode (`$3{,}027{,}818$`),
   `\times10^{-12}` not `e-12`, one decimal place for shares unless the text
   already uses two for a stated reason. Do not introduce a number that is not
   already in the text or in a cited table.
5. **Fewer numbers.** The author's standing rule: do not report quantities from
   estimation runs in the running text. If a paragraph carries three or more
   unrelated numbers that no sentence uses, propose a cut in your report rather
   than deleting silently.
6. **References.** Tables and figures via `\ref{...}`, equations via
   `\eqref{...}`, sections via `Section~\ref{...}`, appendices via
   `Appendix~\ref{...}`. Never hard-code a number (`Table 4` is a finding: turn
   it into `\ref` or report it).
7. **Notation that must not be "fixed".** `\Pi` is the markup bill
   `Π = Σ(1−1/μ_i)p_iy_i` in sections 6 and E — it is *not* the price index;
   the price index is `\mathcal{P}`. `\Omega` is the total cost-share matrix;
   `Ω_{iu}` is the share of input `u` in user `i`'s bill (rows sum to one).
   Do not reorder those indices.
8. **Footnotes.** Prefer none; where a footnote merely restates a clause, fold it
   into the sentence or delete it. Report every footnote you delete.
9. **No file paths or script names in reader-facing prose.** Never write
   `\texttt{cbase2/scripts/...}`, `composition.py` or any other path, module or
   notebook name into the text; provenance of this kind belongs in code
   comments, the replication package and the code-availability statement.
   If a sentence lost its meaning when the path went, delete the sentence
   rather than paraphrase it ("it is generated by recomputing …" says nothing).
10. **No cosmetic churn.** Do not reflow paragraphs, re-wrap lines or reorder
   sentences for style. Minimal diffs only; one logical change per edit.

## Output

After the pass, report:

- a table of every rule × file with the number of changes;
- the list of proposed cuts (numbers or sentences you did *not* remove);
- the build result: `latexmk -pdf -interaction=nonstopmode main.tex` with the
  error count, undefined-reference count and overfull-box count, compared with
  the baseline (0 / 0 / 0). Do not leave the tree unbuildable.

## Guard

If a rule conflicts with the author's prose (e.g. he deliberately spelled out a
percentage for emphasis), leave the text alone and list it under "conflicts".
The goal is a paper that reads as if one person wrote it, not a normalizer.
