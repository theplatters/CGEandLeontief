    We want to find the cost function of $Y(\mathbf x) = \prod_{i=1}^n x_i^{\beta i}$, where $\sum_i^n \beta_i = 1$.

    The cost minisisation problem reads as 
    \begin{gather}
        \min \langle p,x \rangle \\
        Y(x) = 1
    \end{gather}

Which is equivalent to 

    \begin{gather}
        \min \langle p,x \rangle \\
        \log Y(x) = 0
    \end{gather}

The First order conditions are 
$$x_i = \lambda \beta_i \frac{1}{p_i} \quad \forall i$$

Summing over all $j$ we can see, that 
$ \lambda = \sum p_j x_j$

Thus $x_i = \frac{\beta_i}{p_i}\sum p_j x_j $

Inserting into $Y(x) = 1$, leads to 

$\sum_j p_j x_j = \mathcal C(\mathbf p) = \prod_{j=1}^n  \left( \frac {p_j}{\beta_j} \right)^{\beta_j}.$
