# Candidate paper figures from the 5x3 matrix visualisation

Candidate paper figures derived from the executed 5x3 labour-closure x
financing-closure matrix (`matrix_5x3_v10`: BF/ALPHA/BETA/GAMMA/DELTA x
F1/F2/F3, fifteen cells). Generated by `experiments/plot_matrix.jl` (see
`experiments/README.md`, "Plotting the matrix", and
`docs/decisions/ADR-0025-matrix-visualisation-validated-resolve.md`); the
figures are exploratory artifacts written under `plots/` (gitignored, not
committed), and every panel is traceable to the `matrix_5x3-v10-*` run ids
through the driver's validation report.

## 1. Candidate: external account / trade

The recommended figure (`trade` panel of `save_matrix_figures`). Four panels:

- (a1) gross trade flows, exports X and total imports M, in % of GDP per cell
  (`X = 100*gdp_x`; `M = -100*(gdp_m_final + gdp_m_int)`);
- (a2) net external position (F + B_gov, `metrics.external_position`) and the
  programme financing B_gov (`metrics.programme_financing`) per cell — the
  panel that makes the ADR-0019 external-account closure and the F2/F3
  financing-neutrality visible (F2/F3 coincide in the mobile rows;
  GAMMA/DELTA carry F = 0);
- (b) sectoral total-import changes (import content of final + intermediate
  demand, shared p98-clipped colour scale) across the fifteen cells;
- (c) the export exogeneity check: exports are exogenous quantities, so the
  plotted values move only with equilibrium prices.

Data provenance: per-sector import content from `sectoral_trade_flows`
(`src/plots.jl`; mirrors `external_balance_canary`/`gdp_components`),
aggregates from the manifests. Regeneration:

```bash
julia --project=. experiments/plot_matrix.jl --design matrix_5x3_v10
```

(needs GLMakie; `--no-figures` validates and exports the tidy CSVs only).
Source runs: the fifteen `matrix_5x3-v10-*` matrix cells
(`BF/ALPHA/BETA/GAMMA/DELTA` x `F1/F2/F3`); 15/15 validate with zero deltas.

## 2. Exploratory-only figures

The other five panels of `save_matrix_figures`, one line each:

- `overview` — headline metrics (real GDP, consumption, employment, deflator)
  by cell;
- `wages` — sectoral and aggregate wage response by cell;
- `prices` — sectoral price response heatmap across the fifteen cells;
- `quantities` — sectoral quantity response heatmap across the fifteen cells;
- `consumption` — aggregate consumption change, sectoral consumption heatmap,
  and consumption/employment scatter.

Operator's assessment (2026-09-20): useful for exploratory analysis but not
paper candidates as they stand.

Two substantive exploratory findings the figures expose (from the manifests,
cited by run id):

(i) Demand-only shocks leave prices at the baseline in every single-wage
closure — `matrix_5x3-v10-ALPHA-*`, `matrix_5x3-v10-BETA-F[123]`,
`matrix_5x3-v10-GAMMA-*`, `matrix_5x3-v10-DELTA-*`
(`max_abs_price_dev` ~1e-14) — while the eta = 0 `matrix_5x3-v10-BF-*` row
moves them (up to 27.9 % at `matrix_5x3-v10-BF-F2`).

(ii) F2 and F3 are real-neutral in the mobile rows while
`matrix_5x3-v10-GAMMA-F3` / `matrix_5x3-v10-DELTA-F3` raise employment
(1.78 %).

## 3. Manuscript panel figures (one per matrix cell)

The `panel_ls`-style two-panel figure (`revised_manuscript/pictures/panel_ls.png`,
referenced by `revised_manuscript/chapters/ch06_labor_slack.tex` and left untouched),
recreated for the 5x3 matrix as one file per matrix cell —
`revised_manuscript/pictures/panel_5x3_<labour>_<financing>.png` (fifteen files:
`BF/ALPHA/BETA/GAMMA/DELTA` x `F1/F2/F3`)
(`plot_matrix_panel` / `save_matrix_panels` in `ext/matrix_plots.jl`):

- left: grouped bars over the programme sectors (sectors with positive programme
  demand, sorted by programme share descending) for that cell —
  programme demand in % of baseline gross output (`100*g_i/y0_i`, no error bar),
  change in output (`100*(q_i-1)`), change in consumption (`100*(c_i-1)`), and the
  price deviation from the numeraire (`100*(p_i-1)`); error bars on the last three
  series span the **consumption-elasticity range**: min/max over the central cell
  and its two σ variants (σ ∈ {0.6, 0.99}, the cell's θ, ε, η, financing and
  shock fixed; no error bar when no variant converged);
- right: scatter of change in quantities (`100*(q_i-1)`, x) vs change in prices
  (`100*(p_i-1)`, y) over all sectors of the cell — programme sectors highlighted
  with larger markers, other sectors plain; the three largest programme-sector
  points plus the three largest non-programme movers labelled; 0/0 dashed cross;
  legend "Programme sectors" / "Other sectors".

Conventions: bars show the cell, error bars the σ sensitivity (the legacy
`panel_ls` meaning — not the financing range); each file is standalone with
per-cell axis limits. Degenerate scatter ranges get a minimum span (0.05 %
total) with an annotation — prices sit at the baseline in every single-wage
closure (no sectoral-wage channel), so without it the y-axis would repeat
"0.00%" ticks. Titles read
"5x3 matrix panel — \<labour\>-\<financing\> (bars = cell; error bars: σ ∈ {0.6, 0.99})", and
each figure footnotes the design reference (no-programme) baseline, the
programme-demand normalisation, and the elasticity error-bar meaning.

BETA is numerically identical to ALPHA and DELTA reproduces GAMMA to solver precision,
so several of the fifteen files document the same economy (DELTA additionally ignores σ
by construction — its variants re-solve the same model, so its error bars collapse);
see Table 2 of
`paper/tables/matrix_5x3_v10_flows.md` for that statement. Regeneration:

```bash
julia --project=. experiments/plot_matrix.jl --design matrix_5x3_v10 --no-figures --panel-dir revised_manuscript/pictures
```

(needs GLMakie; `--no-figures` suppresses only the six exploratory figures while the
panels are still written).

## How to regenerate / where the data lives

```bash
julia --project=. experiments/plot_matrix.jl --design matrix_5x3_v10
```

Tidy data: `output/<design>_summary.csv` (one row per validated cell) and
`output/<design>_sectoral.csv` (tidy long frame). Figures:
`plots/<design>_<panel>.png` per panel (`overview`, `wages`, `prices`,
`quantities`, `consumption`, `trade`).
